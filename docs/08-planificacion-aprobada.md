La fase de análisis prevista entre el 19 de octubre y el 1 de noviembre queda documentada mediante los requisitos, casos de uso, arquitectura, diagrama de clases y modelo entidad-relación de esta carpeta. Las fases de pruebas, Docker, Docker Hub, GitHub y memoria siguen siendo trabajo futuro. No se considera ninguna de ellas realizada por el mero hecho de estar incluida en la planificación.
